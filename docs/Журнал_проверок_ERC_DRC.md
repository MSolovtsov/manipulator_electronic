# Журнал проверок ERC / DRC

Запись добавляется после каждого прогона ERC (схема) или DRC (плата) в KiCad 10.
Хеш файла — `git hash-object boards/<КОД>/<КОД>.kicad_sch` (или `.kicad_pcb`),
первые 8 знаков; по нему видно, к какой именно версии файла относится проверка.
Отчёты `*.rpt` в репозиторий не попадают — сюда заносится только итог.
Плата не генерируется по схеме, у которой нет записи ERC с актуальным хешем.
