# Список использованных источников

Единый сквозной список для подпроекта `electronics`. На него ссылаются расчёты
в `calc/`, обоснования в `docs/` и пояснения в генераторах схем и плат.

**Правила ведения**

- Нумерация сквозная и задним числом не меняется: новый источник дописывается
  в конец списка. Освободившийся номер не переиспользуется.
- Ссылка в тексте и в комментарии скрипта — `[N]`, где N — номер из этого
  списка. Для формулы указывается ещё и место: `[4, с. 112]`, `[7, табл. 3]`.
- Выходные данные приводятся полностью. Если чего-то не хватает — строка
  остаётся с пометкой «уточнить», и источник не используется в записке, пока
  пометка не снята.
- Строки с пометкой «уточнить» перед сдачей записки должны быть закрыты либо
  удалены вместе со ссылками на них.

**Формат строки**

Книга — автор, название, издание, город, издательство, год, страницы.
Стандарт — обозначение, название, год введения.
Документация компонента — производитель, обозначение документа, название,
ревизия, год.
