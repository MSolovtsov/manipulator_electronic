# Шрифт ГОСТ 2.304 (тип Б) для схем KiCad

Семейство **«GOST 2.304»** — свободная реализация чертёжного шрифта по ГОСТ 2.304-81,
источник: https://github.com/MishkinIN/Font_GOST_2.304 (лицензия GPL v3, см. LICENSE).

Файлы: `gost_2.304.ttf` (Regular), `gost_2.304_italic.ttf` (Italic — основной для схем),
`gost_2.304_Bold.ttf`, `gost_2.304_Bold_Italic.ttf`.

Установка на macOS: открыть каждый .ttf двойным щелчком → «Установить шрифт» (Font Book),
перезапустить KiCad. Схемы генерируются с `(font (face "GOST 2.304") …)`; без установленного
шрифта KiCad подставит свой. Чтобы файл был самодостаточным, в KiCad: Файл → Настройки
схемы → Встроенные файлы → «Встраивать шрифты», затем сохранить.
